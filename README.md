# Quebec Governance Monitor – news-alerts

Daily bilingual (FR/EN) digest on Quebec governance, published with Jekyll on GitHub Pages:
https://quebec-taxpayer.github.io/news-alerts/

## Add a day
Create `_posts/YYYY-MM-DD-digest.md` (copy an existing day), fill in the front matter
(`title`, `date`, `summary`, `story_count`, `tags`) and the stories. Commit to `main`;
the home page, archive and topics update automatically.

Tags used for topics: `it-digital`, `crown-corporations`, `procurement`.
