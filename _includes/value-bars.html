{%- comment -%} Simple value bars, gauges and dot counts (CSS only). Usage: {% include value-bars.html data=V.cost %} Data: id, cap_en/fr, scale (the 100% width), optional target {v, en, fr} (vertical marker), dots (true = draw "scale" squares, for small counts), rows [{label_en/fr, v, base (optional: part up to base is plain, base..v is highlighted), open (true = "at least": open end), show_en/fr (the number as text), hl_en/fr (what the highlighted part is), links [{url,en,fr}]}], note_en/fr. The bar graphic is aria-hidden; each row's label + number + note are plain text. {%- endcomment -%} {%- assign B = include.data -%}
